# 505 Tracker — Construction Budget Tracker

Built by a framer, for framers. Track every dollar on your spec house or remodel — by trade, by draw, by change order.

## What It Does

- **Budget tab** — line items by trade (framing, concrete, electrical, etc.), search, filter, add/edit
- **Draws tab** — log payments (check/ACH/wire), running paid total
- **Changes tab** — pending and approved change orders
- **Multi-job file cabinet** — switch between jobs, each fully isolated
- **CSV export** — take your data anywhere

## Built With

- TanStack Start (React SSR)
- PGLite (SQLite in the browser — no backend required)
- Tailwind CSS
